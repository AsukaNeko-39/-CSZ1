# 湖湘农耕文化地图 · ideal.md

网站版本：**CSZ2版**。原整理日期：2026-09-09；欢迎页设计修订：2026-09-22。

按本次“ideal”的要求，本文件整理设计理念、决策依据与后续方向。已落地的具体规范见 [design.md](design.md)。项目原有 `ideas.md` 保留为早期方案，不代表当前待办全部要做。

## 产品定位

以湖南省地图连接湖湘农耕文化的地点、历史演进、土地制度、民俗与器物。先用欢迎页建立文化主题，再让用户按地点或专题探索；详细资料能够继续读，图片能够看清。

面向文化展示、研学和普通访客。界面说明优先使用自然中文，不把技术配置、调试信息或建设过程放进普通访客流程。

## 已采用的设计判断

| 判断 | 为什么这样做 | 当前体现 |
| --- | --- | --- |
| 先欢迎，再探索 | 外部访客需要知道网站的主题 | 新打开链接先进入欢迎页，分享入口统一 |
| 五个专题相互关联 | 土地制度、民俗不能被地图或节气替代 | 顶部五项导航，地图底部四个专题入口，详细页前后互跳 |
| 资料完整，首页克制 | 首页用于发现，详细页用于阅读 | 简洁预览、完整正文、卡片内翻页与原图入口 |
| 图片主体比装裱更重要 | 缩略图太小或被截得过窄就无法辨认 | 首页贴边、逐图取景，详情完整适配 |
| 背景是贯穿内容的环境 | 单独的首屏背景容易在长页面下方中断 | 山水、田野延续到页尾和手机横滑末栏 |
| 动效帮助定位 | 移动、缩放应解释“进入哪里、正在看哪里” | 渐进放大、箭头反馈、轻微浮起和短过场 |
| 操作连续 | 看过欢迎页后，站内刷新返回不应反复打断 | 区分新访问与站内历史恢复 |

“呼吸感”主要来自清楚的层级、文本行距和从容的过场，不意味着给每张图添加厚留白。“完整呈现”针对资料正文和详细页原图，也不意味着所有首页缩略图只能缩小到画框中央。

## 已替换的方案

| 早期方案 | 本次采用方案 | 原因 |
| --- | --- | --- |
| 顶部与底部重复五个入口、民俗以节气展示 | 顶部五项导航；底部四个专题；民俗展示真实民俗资料 | 2026-09-21 用户标注图明确取消底部地图模块和节气 |
| 图片统一铺满所有场景 | 首页适度取景，详细页保留完整原图 | 兼顾首页饱满与资料可读 |
| 统一厚边框、四件文物排成狭长竖栏 | 贴边图文卡，文物两行两列 | 减少留白，主体更大，组内整齐 |
| 圆形放大镜或图外放大窗 | 长图本身平滑放大 | 用户多轮反馈确定的交互 |
| 金绿渐变光影 | 1→2.8 倍渐进缩放 | “渐变放大”需求指尺寸变化 |
| 分享当前栏目 URL | 分享欢迎页 URL | 外部打开先看到封面 |
| 仅有链接可访问的旧分享服务 | 当前公开 GitHub Pages + 私有源码 | 用户后续明确要求公开可转发；不把禁索引当权限控制 |
| 标题下标语与正文首句重复 | 删除独立标语，正文保留 | 减少重复信息 |

上述记录是决策历史，不限制用户以后明确采用新的设计方向。

## 后续方向：尚未实施，也不代表本次授权执行

| 优先级 | 候选工作 | 依据/验收条件 |
| --- | --- | --- |
| 较高 | 真机微信、iOS/Android 浏览器核对 | 记录实际机型与浏览器；检查外部打开、返回、复制权限、长图、横滑。桌面模拟不能替代实测 |
| 较高 | 梳理地图点位面板中的占位动作 | `PointDetail.tsx` 的“查看详情、路线规划、一键分享”目前仍有“功能即将上线”提示；先明确功能范围与资料来源，不把顶部分享修复等同于这些动作已实现 |
| 适中 | 进一步降低首次加载体积 | 当前构建有约 800kB 主 JS 的体积提示；先测量，再按专题拆分或延迟载入，保持入口和资料完整 |
| 适中 | 字体及地图外部资源的可靠性 | 当前使用外部字体与地图相关资源；根据使用环境评估本地托管、缓存及加载失败体验，先核对许可 |
| 适中 | 长期资料维护与来源索引 | 新增资料时保留来源、图片说明、年代与关联；明确修订责任，不凭生成内容补历史事实 |
| 适中 | 阅读辅助与可访问性细化 | 在真实键盘、触屏和减少动态效果场景测试；高密度卡片仍应可读 |

候选方向按用户当前目标选择，不在普通文字或样式修复中自动展开。

## 未来版本如何命名

当前网站按用户 2026-09-21 的明确要求统一称 **CSZ2版**。源码提交号标识具体技术快照，PDF 页数表示记录长度，都不自动改变版本名。只有用户明确指定新名称时再更新 `design.md`、本文件、skill 快照、仓库说明和相应修改记录。

改版前先确认要保留哪些原作优点；改版后用同一组代表场景比较。避免把一次局部修复演变为欢迎页、背景、五个专题和已有入口的整体回退。


## 2026-09-21 欢迎页设计更新

用户提供新的欢迎页参考，明确要求以稻谷为背景并呈现随风飘动的动态。本轮采用米白留白、居中“农耕文化 / 数字地图”及浅金稻田，替代旧欢迎页左右分栏和梯田照片。保留先欢迎再探索的入口逻辑，原始介绍收纳至“关于地图”，避免长文挤压首屏构图。

风动分成贯穿稻田的风浪与单株轻微摆动，前后大小形成纵深。文字不跟随晃动。采用本地程序绘制以保持清晰与轻量，提供暂停控制，遵循系统减少动态效果；主办承办信息保留。原五专题及其设计约定继续有效。

这是用户新要求对旧欢迎页方案的明确替换。以后不得为了匹配旧欢迎页截图恢复梯田照片和左右分栏；新的明确用户要求仍优先。本轮仅完成本地实现与验证，发布另按用户后续要求执行。

欢迎页的满屏范围以实际页面容器为准；窗口最大化、页面缩放和嵌入浏览器的可用高度不同，短屏排版规则也应保留这一约束，避免露出其他页面使用的场景背景。


## 2026-09-21 精简入口与提升阅读

本次用户明确要求取消全站顶部统计栏、地图底部的“地图浏览”模块及节气功能。顶部地图与四个专题仍保留，底部集中展示四个专题。新要求优先于旧五栏截图和文档，不能再恢复重复入口。

发展脉络中间工具栏与上方阶段标签功能重复，已删除；腾出的空间用于更宽、更高的阅读卡片。标签切换时代，卡片翻页阅读原文。文化展示不能依靠小而浅的文字营造精致感，分类、年代、导航和说明适度加大并加深，同时保留宣纸与棕金色调。正文分页继续按实际字体与空间计算，资料不删减。

## 2026-09-21 入口卡片的通透感

地图底部土地制度、民俗文化、重要文物入口采用暖色液态玻璃效果，替换原来平实的米白底。田野背景透入按钮，亮边与投影负责区分可点击区域；较深的文字与清晰的原图保证可读性。透明只用于按钮表面，不能降低整卡透明度。风格保持棕金色调，悬停与按下反馈轻微，键盘和减少动态效果同样可用。

页尾“继续探索”延续同一套玻璃按钮风格，取消各目的地混用照片与插画的背景。同级入口通过一致尺寸、文字位置与交互反馈表达同一层级，目的地靠清晰标题与说明区分。2026-09-21 已同步到所有使用 SectionJourney 的专题页。

欢迎页‘探索地图’主按钮按最新要求改为圆角矩形，以适度圆角柔化入口外观，保留原有文字与布局。

欢迎页主题短句按用户反馈再放大 2px，保持一行呈现及原有层级。

CSZ2 是用户明确命名的本轮完成版。通过私有源码的 csz2 标签保留可追溯快照，公开网页沿用现有地址；旧版本记录作为历史保存，不把历史说明误当成当前界面。


## 2026-09-22 水墨山水欢迎页

用户最新截图将视觉方向改为完整水墨农耕山水，替代9月21日的留白风动稻田。保留参考中的梯田、水车、牛耕、莲荷与山峦关系，使用内置图像生成工具进行高清重绘，清理截图中的文字和按钮；主标题、主题短句及入口作为独立网页元素呈现，避免把网站变成一张不能交互的截图。

背景承载文化场景，白色标题与柔和遮罩负责阅读层级，浅色12px圆角按钮与此前确认的入口手感衔接。手机裁取中央梯田，不压缩整幅横图形成空白。原介绍仍可通过右下角按钮阅读。最新要求优先于此前“不得恢复梯田照片”等针对当时旧方案的限制，本轮使用修复插画而非旧照片。
