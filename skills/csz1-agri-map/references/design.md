# 湖湘农耕文化地图 · design.md

网站版本：**CSZ1版**。整理日期：2026-09-09。界面基线源码：`364a36668ad5ce94dbf63c002fdbb74659e54520`。

本文记录当前采用的设计与实现约定；后续明确的新需求可以更新这些约定。设计理念、已放弃的方案及待办见 [ideal.md](ideal.md)。`ideas.md`、`docs/design-system.md` 和 `reference-layout-notes.md` 的旧内容是历史资料，不能直接当作现行验收标准。

## 1. 页面结构与文案

以“古籍地图”为视觉方向：宣纸底色、棕金线条、印章红、田野山水与实物资料图共同构成文化展示。地图与正文需要阅读空间，缩略图内部则尽量饱满，避免用宽内边距缩小主体。

| 层级 | 当前结构 | 维护重点 |
| --- | --- | --- |
| 欢迎页 | 品牌印章、湖湘农耕文化大标题、介绍正文、进入文化地图按钮、梯田图片、主承办信息 | 标题下不再单列“农耕文化是耕地保护的力量源泉”；这句话仍保留在正文开头 |
| 五个主专题 | 地图浏览、发展脉络、土地制度、民俗文化、重要文物 | 五个专题均保留；名称是“民俗文化”，不是“民俗与四时” |
| 地图页 | 顶部导航和统计、地图、图层筛选、点位详情、底部五个专题入口、页脚 | 底部入口与顶部专题一致；线路归于地图入口，节气与耕作时序归于民俗入口 |
| 详细页 | 专题标题、筛选或时代导航、内容卡片、详情/高清原图、专题互跳 | 需求文档中各专题的详细内容要求在详细页落实；不把全部长文硬塞进首页 |
| 辅助页面 | 主题线路、二十四节气 | 保留现有入口，不替代五个主专题 |

当前资料规模为文化点位 15 处、发展阶段 5 个、土地制度 9 项、民俗文化 19 项、重要文物 22 件，另有 24 个节气和 3 条线路。这是本次基线，后续增加资料应同步数据与统计，不能把旧数量写死为长期上限。

## 2. 视觉语言

| 角色 | 参考色 | 使用方式 |
| --- | --- | --- |
| 稻穗金 | `#8B6914` | 按钮、重点标签、导航选中、细边框 |
| 山水绿 | `#4A7C59` | 农业建设与实践点位、田野和山林意象 |
| 印章红 | `#C41E3A` | 品牌印章与重要场馆标记，少量点缀 |
| 宣纸米白 | `#F5F0E8`；局部 `#faf6ee` | 页面、纸色面板、阅读底色 |
| 墨色 | `#2C2418`；局部深棕 | 正文和标题 |

以上是设计参考值；实际主题变量以 `client/src/index.css` 中的 OKLCH 值为准，不把两套色值当成精确换算。标题、节头、地图标签沿用 Noto Serif SC/宋体气质；正文和控件按已有 `font-serif`、`font-sans` 分工。字体加载失败时要有系统字体回退，不能靠某一次字体加载下的宽度估算长文分页。

面板以浅纸色、细金线和轻阴影建立层次。圆角、透明度与边框沿用相邻组件；不把文化阅读页改成高对比商业仪表盘。文本和交互提示必须能从背景中辨认。

## 3. 背景与素材

- 欢迎页和公共过场使用 `routes-hero-bg.webp`；发展脉络使用 `timeline-hero-bg.webp`。专题具体背景由 `sceneryStyle()` 及对应页面决定。
- `bottom-field-decor.webp` 是首页底部和详细页尾部的重要田野装饰。检查整个滚动内容，不能只检查首屏；窄屏横滑到末栏时仍要有背景。
- 背景层由 `CultureScenery.tsx`、`CulturePageTransition.tsx` 和 `culture-refinement.css` 协同实现。修复背景时先检查实际资源路径、伪元素、遮罩、层级、容器高度与滚动，不盲目提高不透明度。
- 实际资料图在 `client/public/materials/`；原项目装饰素材主要在 `client/public/manus-storage/`。资源引用走 `assetUrl()`，保留 GitHub Pages 的子路径。
- 使用 AI 时适合处理装饰背景或原图周边的环境延展。不要用生成内容替代年代图小字、铭文、器型和资料正文；保留原图，并记录生成素材的用途。当前首页竖版文物两侧采用原图背景延展，并非 AI 重绘文物。

## 4. 首页底部图片

首页缩略图的任务是让用户辨认内容并进入详情，按整组视觉秩序安排，不能让原图纵横比直接决定每张卡片的大小。

| 区域/图片 | CSZ1 当前处理 | 保留要点 |
| --- | --- | --- |
| 土地制度三张图 | 同组等大展框；图片贴边、无额外内边距；逐张调整取景 | 《诗经》书名、简牍和契证的辨识信息可见，完整原图留在详情 |
| 重要文物四张图 | 两行两列等大图文卡；图片贴齐卡片边缘，图名独立排版 | 同组画框等大，图名不溢出，不用一圈厚白边装裱 |
| 大禾人面纹方鼎 | 加大图像区域，按中心偏下取景；窄桌面窗口改为完整适配 | 保留耳、器身和足的辨认；“更大”不等于切掉重要结构 |
| 素纱单衣 | 按画框铺满，适度裁去左右两端 | 领口、主体和下摆可辨；不额外悬停放大造成二次裁切 |
| 皿方罍 | 前景完整适配，原图背景延展填充两侧 | 顶盖、器身、底座完整，延展不改变原件 |
| 陶釜 | 优先放大器物，压缩展柜顶部与底座所占面积 | 保留器口和主体形态 |

实现入口是 `BottomModules.tsx` 与 `.heritage-dock` 下的样式。文物图片列当前使用 `min(60%, 96px)`；1024–1190px 有针对窄卡片的适配。它们是当前实现参数，可以按新需求调节，但要重新检查四件文物，而不是统一套一个裁切值。

首页卡片悬停保留轻微上浮、边框/阴影和箭头反馈。图片本身不追加缩放裁切；减少动态效果设置下停用位移。

## 5. 详细页与发展脉络

- 土地制度、重要文物详细列表与弹窗采用完整配图方式，保留比例、图名与高清原图入口。**首页缩略图适度裁切，不代表详细页也可以裁切。**
- 五阶段发展卡片在同一屏幕条件下保持一致尺寸。长文使用 `BookReader.tsx` 按字体和实际空间分页，全文、关键事件和阅读顺序必须保留；不能用省略号冒充分页。
- 下方发展脉络图使用原始高清图 `materials/01发展脉络图.jpg`。`InteractiveChart.tsx` 的当前交互是图片从 1 倍平滑放大至 2.8 倍，移动鼠标调整局部位置，移开约 480ms 还原。
- “渐变放大”指平滑缩放，不是颜色光影。圆形放大镜、独立图外放大窗与金绿光影均不是现行方案。
- 悬停移动只缓存固定画框的位置，用 `requestAnimationFrame` 合并事件并平移图层；不要在每次鼠标事件里反复测量或绘制整张高清图。滚动、改变窗口、失焦或点击展开时清理旧位置。
- 触屏继续点击展开高清图；键盘可打开；减少动态效果设置下停用悬停缩放。

## 6. 导航、分享与过场

外部新打开网站，包括旧链接中的 `#artifacts`、`#timeline` 或详情后缀，先显示欢迎页并将地址同步到 `#cover`；用户再点击“进入文化地图”。站内刷新和浏览器前进后退可以恢复已有栏目。该区别由 `lib/navigation.ts` 的入口逻辑和历史记录标记实现，不依赖“已看过欢迎页”的永久存储。

顶部分享按钮生成欢迎页链接并去掉旧的 `v`、`preview` 参数；复制失败时给出可选中、可长按复制的链接窗口。不要再次调用仅适用于旧分享服务的 `/__share-link` 来生成 GitHub Pages 链接。保留印章返回欢迎页、详细页的前后专题与页尾“继续探索”。

页面过场约 380ms 进入、180ms 退出，旧画面约 210ms 清除；保留短暂交叠和阅读呼吸感。快速连点切换时只保留必要的旧画面，离开页不可继续交互。导航测试需要同时查看当前画面和地址，而非只看截图。

## 7. 响应式与验收

地图页采用全高应用布局；内容页在场景容器内滚动。不要将旧参考图的“所有页面一屏完成”套到长内容详细页。

首页底部在宽屏为五栏；1024–1190px 调整密度；1023px 以下横向滑动，移动端显示紧凑主导航。涉及首页图栏时覆盖 1920、1440、1366、1024、768、390px 宽度；普通小改仅检查受影响的尺寸和路径。

通过标准：图片加载成功、同组卡片对齐、图名不溢出、主体可辨、背景延续、无整页横向溢出；入口、详情及返回仍可操作。颜色和间距不能只凭数值验收，应看实际截图。微信客户端未实测时，只能报告浏览器/手机尺寸验证结果。
