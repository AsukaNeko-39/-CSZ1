# CSZ2版修改记录

版本标签：`csz2` · 日期：2026-09-21

本版基于第二版私有项目，汇总用户本轮确认的欢迎页、入口布局、阅读和按钮调整。

## 欢迎页

- 以米白背景、居中“农耕文化 / 数字地图”和浅金动态稻田替代原布局；稻秆与谷粒随风摆动。
- 动画可暂停，遵循减少动态效果设置；原介绍完整收纳在“关于地图”。
- 修复窗口最大化及短屏状态下底部露出旧背景的问题。
- “探索地图”按钮采用 12px 圆角矩形；主题短句字号为桌面 17px、手机 14px。

## 页面结构与阅读

- 全站取消顶部数量统计栏；地图下方只展示发展脉络、土地制度、民俗文化、重要文物四个专题。
- 移除节气入口及独立页面，民俗预览使用现有耕作时序、饮食、服饰和端午资料。
- 发展脉络取消重复章节切换栏，使用上方五阶段标签；卡片加宽加高。
- 分类、年代、导航和正文适度放大并加深，完整正文继续分页。
- 修复响应式宽度变化及中文字体加载引起的分页测量偏差，保留全部正文与关键事件。

## 玻璃按钮

- 土地制度、民俗文化、重要文物的 11 个地图入口统一使用半透明玻璃效果。
- 页尾“继续探索”的四个按钮使用同一表面，统一高度、边框、圆角和文字位置。
- 保留悬停、按下、键盘焦点以及减少动态效果支持。

## 验证与交付

- 已检查 320 至 1920px 的代表宽度，无页面横向溢出。
- 1920、1440、390px 下，五阶段逐页拼合与原文逐字一致。
- 已验证专题入口、详情、返回、键盘焦点、欢迎页入口及手机布局。
- 已有 14 项导航测试通过；发布前执行类型检查和 GitHub Pages 子路径构建。
- 微信客户端未进行真机验证。构建中已有的主包体积提示保留，未扩展到无关优化。
